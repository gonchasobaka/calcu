# Продвинутый Калькулятор 2025

Современный научный калькулятор с расширенными возможностями, написанный на Python.

## Возможности

### Базовые операции
- Арифметические операции: `+`, `-`, `*`, `/`
- Возведение в степень: `**` или `^`
- Скобки для группировки операций

### Научные функции
- **Тригонометрия**: `sin()`, `cos()`, `tan()`, `asin()`, `acos()`, `atan()`
- **Гиперболические функции**: `sinh()`, `cosh()`, `tanh()`
- **Логарифмы**: `log()`, `log10()`, `log2()`
- **Математические функции**: `sqrt()`, `exp()`, `factorial()`, `abs()`
- **Округление**: `floor()`, `ceil()`, `round()`, `trunc()`
- **GCD/LCM**: `gcd()`, `lcm()`

### Константы
- `pi` или `π` - Число Пи (3.14159...)
- `e` - Число Эйлера (2.71828...)
- `phi` - Золотое сечение (1.61803...)
- `c` - Скорость света (299,792,458 м/с)
- `g` - Ускорение свободного падения (9.80665 м/с²)

### Дополнительные возможности
- **История вычислений** с автоматическим сохранением
- **Память калькулятора** (сохранение, вызов, добавление, вычитание)
- **Переменные** для сохранения промежуточных результатов
- **Конвертация единиц измерения** (длина, масса, температура, объем, время)

## Установка

Калькулятор не требует дополнительных библиотек, работает на стандартной установке Python 3.6+.

```bash
# Клонировать репозиторий
git clone <repository-url>
cd calcu

# Сделать скрипт исполняемым (Linux/Mac)
chmod +x calculator2025.py
```

## Использование

### Запуск калькулятора

```bash
python3 calculator2025.py
```

или (если скрипт исполняемый):

```bash
./calculator2025.py
```

### Примеры вычислений

#### Базовые вычисления
```
>>> 2 + 2
  = 4

>>> (10 + 5) * 3
  = 45

>>> 2 ** 10
  = 1024
```

#### Научные функции
```
>>> sqrt(144)
  = 12.0

>>> sin(pi/2)
  = 1.0

>>> log10(1000)
  = 3.0

>>> factorial(5)
  = 120
```

#### Использование констант
```
>>> pi * 2
  = 6.283185307179586

>>> e ** 2
  = 7.38905609893065

>>> c / 1000
  = 299792.458
```

#### Работа с памятью
```
>>> mem store 42
Сохранено в память: 42.0

>>> mem recall
Значение из памяти: 42.0

>>> mem add 8
Добавлено к памяти: 8.0, новое значение: 50.0

>>> mem clear
Память очищена
```

#### Переменные
```
>>> var set x 10
Переменная x = 10.0

>>> var set y 20
Переменная y = 20.0

>>> x + y
  = 30.0

>>> var list
ПЕРЕМЕННЫЕ:
  x = 10.0
  y = 20.0
```

#### Конвертация единиц
```
>>> convert 100 cm m
  100.0 cm = 1.0 m

>>> convert 32 f c
  32.0 f = 0.0 c

>>> convert 5 km mile
  5.0 km = 3.106855 mile

>>> convert 2.5 hour s
  2.5 hour = 9000.0 s
```

#### История вычислений
```
>>> history
ИСТОРИЯ ВЫЧИСЛЕНИЙ:
------------------------------------------------------------
1. [2025-10-21 10:30:15]
   2 + 2 = 4.0
2. [2025-10-21 10:30:20]
   sqrt(144) = 12.0

>>> history 5
(показывает последние 5 вычислений)

>>> clear history
История очищена
```

## Поддерживаемые единицы измерения

### Длина
- `mm`, `cm`, `m`, `km` (метрическая система)
- `inch`, `ft`, `yard`, `mile` (британская система)

### Масса
- `mg`, `g`, `kg`, `ton` (метрическая система)
- `oz`, `lb` (британская система)

### Температура
- `c` (Цельсий)
- `f` (Фаренгейт)
- `k` (Кельвин)

### Объем
- `ml`, `cl`, `dl`, `l` (литры)
- `gal` (галлоны)

### Время
- `s` (секунды)
- `min` (минуты)
- `hour` (часы)
- `day` (дни)
- `week` (недели)

### Площадь
- `cm2`, `m2`, `km2`
- `hectare` (гектары)

## Команды калькулятора

| Команда | Описание |
|---------|----------|
| `help` | Показать справку |
| `history` | Показать последние 10 вычислений |
| `history <n>` | Показать последние n вычислений |
| `clear history` | Очистить историю |
| `mem store <значение>` | Сохранить значение в память |
| `mem recall` | Вспомнить значение из памяти |
| `mem clear` | Очистить память |
| `mem add <значение>` | Добавить к памяти |
| `mem sub <значение>` | Вычесть из памяти |
| `var set <имя> <значение>` | Установить переменную |
| `var get <имя>` | Получить значение переменной |
| `var list` | Показать все переменные |
| `var clear` | Очистить все переменные |
| `convert <значение> <из> <в>` | Конвертировать единицы |
| `quit` или `exit` | Выход из калькулятора |

## Файл истории

История вычислений автоматически сохраняется в файл `~/.calculator2025_history.json` и загружается при следующем запуске калькулятора.
