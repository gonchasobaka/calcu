# Инструкция для Windows 10

## Шаг 1: Установка Python

1. Скачайте Python с https://www.python.org/downloads/
2. Запустите установщик
3. **ВАЖНО:** Отметьте галочку "Add Python to PATH"
4. Нажмите "Install Now"
5. Дождитесь завершения установки

## Шаг 2: Проверка установки

Откройте **Командную строку** (Win + R → cmd → Enter) и выполните:

```cmd
python --version
```

Должно вывести что-то вроде: `Python 3.11.x`

## Шаг 3: Получение файлов

### Если есть git:
```cmd
git clone <URL_репозитория>
cd calcu
```

### Если нет git:
1. Скачайте ZIP архив репозитория
2. Распакуйте в удобную папку
3. Откройте командную строку в этой папке:
   - Shift + Правая кнопка мыши в папке
   - "Открыть окно команд здесь" или "Открыть PowerShell здесь"

## Шаг 4: Запуск калькулятора

### Вариант A: Двойной клик
Просто дважды щелкните по файлу **calculator2025.py**

### Вариант B: Командная строка
```cmd
python calculator2025.py
```

### Вариант C: Автоматический тест
```cmd
test_windows.bat
```

## Шаг 5: Использование калькулятора

После запуска появится приглашение `>>>`. Введите:

```
>>> 2 + 2
  = 4

>>> sqrt(144)
  = 12.0

>>> sin(pi/2)
  = 1.0

>>> help
(показывает справку)

>>> quit
(выход)
```

## Возможные проблемы

### Python не найден
**Проблема:** `'python' is not recognized as an internal or external command`

**Решение:**
- Переустановите Python с галочкой "Add Python to PATH"
- Или используйте полный путь: `C:\Python311\python.exe calculator2025.py`

### Кодировка (кириллица не отображается)
**Проблема:** Вместо русских букв квадратики или знаки вопроса

**Решение в cmd:**
```cmd
chcp 65001
python calculator2025.py
```

**Решение в PowerShell:**
```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
python calculator2025.py
```

### Файл открывается и сразу закрывается
**Решение:** Запускайте через командную строку, а не двойным кликом

## Создание ярлыка для быстрого запуска

1. Правой кнопкой на `calculator2025.py` → Создать ярлык
2. Правой кнопкой на ярлыке → Свойства
3. В поле "Объект" добавьте перед путем: `python `
4. Пример: `python "C:\Users\YourName\calcu\calculator2025.py"`
5. Нажмите OK
6. Теперь можно запускать калькулятор двойным кликом по ярлыку

## Дополнительно

### Запуск в фоновом режиме
Создайте файл `calculator.vbs`:

```vbs
Set objShell = CreateObject("WScript.Shell")
objShell.Run "python calculator2025.py", 1, False
```

### Добавление в меню Пуск
1. Создайте ярлык калькулятора
2. Скопируйте его в: `C:\ProgramData\Microsoft\Windows\Start Menu\Programs`

## Удаление

Просто удалите папку `calcu`. Калькулятор не создает записей в реестре и не устанавливает системные файлы.

## Поддержка

Если возникли проблемы:
1. Убедитесь, что Python 3.6+ установлен
2. Проверьте, что все файлы проекта на месте
3. Запустите `test_windows.bat` для диагностики
