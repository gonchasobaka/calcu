# Быстрый старт - Калькулятор 2025

## Запуск

```bash
python3 calculator2025.py
```

## Примеры команд

### Базовые вычисления
```
>>> 2 + 2
>>> sqrt(144)
>>> 2 ** 10
>>> (10 + 5) * 3
```

### Научные функции
```
>>> sin(pi/2)
>>> log10(1000)
>>> factorial(5)
>>> exp(2)
```

### Работа с переменными
```
>>> var set x 10
>>> var set y 20
>>> x + y
>>> var list
```

### Конвертация единиц
```
>>> convert 100 cm m
>>> convert 32 f c
>>> convert 1 hour min
```

### Память
```
>>> mem store 42
>>> mem recall
>>> mem add 10
```

### Справка и история
```
>>> help
>>> history
>>> history 10
```

### Выход
```
>>> quit
```

## Запуск примеров

python3 examples.py
