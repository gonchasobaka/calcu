# Инструкция по скачиванию репозитория

## Ваш репозиторий
- **Название:** gonchasobaka/calcu
- **URL:** https://github.com/gonchasobaka/calcu

## ⭐ САМЫЙ ПРОСТОЙ СПОСОБ (рекомендуется)

### Шаг 1: Скачать ZIP
1. Перейдите на: https://github.com/gonchasobaka/calcu
2. Нажмите зеленую кнопку **< > Code**
3. Выберите **Download ZIP**
4. Сохраните файл на компьютер

### Шаг 2: Распаковать
1. Найдите скачанный файл `calcu-main.zip` (обычно в папке Загрузки)
2. Правой кнопкой мыши → **Извлечь всё...**
3. Выберите папку, например `C:\Projects\calcu`
4. Нажмите **Извлечь**

### Шаг 3: Запустить
1. Откройте папку с распакованными файлами
2. Найдите файл `test_windows.bat`
3. Дважды щелкните по нему
4. Калькулятор запустится!

## 💻 СПОСОБ С GIT (для опытных)

### Если Git установлен:

```cmd

cd C:\Users\ВашеИмя\Documents

# Клонировать репозиторий
git clone https://github.com/gonchasobaka/calcu.git

# Перейти в папку проекта

```

### Если Git НЕ установлен:

1. Скачайте Git: https://git-scm.com/download/win

3. Перезапустите командную строку
4. Выполните команды выше
